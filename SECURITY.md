# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x | ✅ |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Contact the maintainer privately (GitHub profile) with:
- affected component/version
- reproduction steps
- impact assessment

You will get an acknowledgement as soon as possible.

## Secrets

This kit intentionally excludes secrets. If you believe a credential was committed,
rotate it immediately and report it.
